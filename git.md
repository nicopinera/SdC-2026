# Tutorial git

## Clonar el repo

```bash
git clone <url>
```

## Verificar la rama

```bash
git branch
```

## Cambiar de Rama

```bash
git checkout <nombre_rama>
```

## Agregar Cambios a stagging

```bash
git add [. | <ruta_archivo>]
```

## Realizar Commit

```bash
git commit -m "<Mensaje lindo y descriptivo>
```

## Empujar Cambios a Repositorio Remoto

```bash
git push
```

## Traer cambios del repositorio remoto

```bash
git pull
```
